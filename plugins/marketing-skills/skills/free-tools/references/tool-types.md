## Comparison by Type

Practitioner estimates, not measurements; use them to compare options, then validate with your own data.

| Type | Build effort | Lead potential | Search value | Share potential |
|------|--------------|----------------|--------------|-----------------|
| Calculator | Low-medium: days for a simple formula, 1-2 weeks for a multi-variable model | High | Medium-high | Medium |
| Generator | Low (template) to high (LLM-powered, 1-2 weeks plus API costs) | Medium | High | High |
| Checker (analyzer) | Medium-high: days for text analysis, 1-2 weeks for URL crawling | High | Very high | High |
| Grader (analyzer) | Medium: about 1-2 weeks; the rubric matters more than the tech | Very high | High for niche graders | Medium-high |
| Converter | Very low to low: usually client-side, 1-2 days | Low | Medium; large utility sites dominate generic terms | Low |
| Template (library) | Very low: hours to a day | Very high | High; competitive but high intent | Medium |
| Data visualization | High: 2-6 weeks, plus data upkeep | Medium | Very high if the data is unique | Very high if the data surprises |

## Calculators

**Best for**: Decisions involving numbers, comparisons, estimates

**Examples**:
- ROI calculator
- Savings calculator
- Cost comparison tool
- Salary calculator
- Tax estimator
- Pricing estimator
- Compound interest calculator
- Break-even calculator

**Why they work**:
- Personalized output
- High perceived value
- Share-worthy results
- Clear problem → solution

**Implementation tips**:
- Keep inputs simple
- Show calculations transparently
- Make results shareable
- Add "powered by" branding
- Use sliders for numeric ranges and update results live
- Cite the formula and assumptions: a calculator with a stated method is shareable content, not just a widget
- Offer "send this to myself" so the lead capture feels natural

## Generators

**Best for**: Creating something useful quickly

**Examples**:
- Policy generator (privacy, terms)
- Template generator
- Name/tagline generator
- Email subject line generator
- Resume builder
- Color palette generator
- Logo maker
- Contract generator

**Why they work**:
- Tangible output
- Saves time
- Easily shared
- Repeat usage

**Implementation tips**:
- Output should be immediately usable
- Allow customization
- Offer download/export options
- Include email gating for premium outputs
- Show an example output before the user enters anything
- Generate 3-5 variations, not one, with a copy button and "generate again"
- For LLM-powered generators, put the API cost per use into the business case

## Analyzers/Auditors

**Best for**: Evaluating existing work or assets

**Examples**:
- Website grader
- SEO analyzer
- Email subject tester
- Headline analyzer
- Security checker
- Performance auditor
- Accessibility checker
- Code quality analyzer

**Why they work**:
- Curiosity-driven
- Personalized insights
- Creates awareness of problems
- Natural lead to solution

**Implementation tips**:
- Score or grade for gamification
- Benchmark against averages
- Provide actionable recommendations
- Follow up with improvement offers
- Group findings as critical, warnings and passed, ranked by impact
- Show progress while the analysis runs
- For graders, define the rubric first; break the grade into components ("Design: A, Copy: C, CTA: D") and explain why and how to improve each. The improvement advice is where the lead capture is earned.

## Testers/Validators

**Best for**: Checking if something works

**Examples**:
- Meta tag preview
- Email rendering test
- Mobile-friendly test
- Speed test
- DNS checker
- SSL certificate checker
- Redirect checker
- Broken link finder

**Why they work**:
- Immediate utility
- Bookmark-worthy
- Repeat usage
- Professional necessity

**Implementation tips**:
- Fast results are essential
- Show pass/fail clearly
- Provide fix instructions
- Integrate with your product where relevant

## Converters

**Best for**: Transforming input from one format to another — pure utility

**Examples**:
- Markdown to HTML
- Timestamp converter
- CSV to JSON
- Time zone converter
- Design tokens to CSS

**Why they work**:
- Immediate utility
- Bookmarked and reused

**When to build**: only when the conversion is specific to your audience's workflow, such as a design tool building a design-token-to-CSS converter. Generic converters are dominated by large utility sites with years of search authority, and people bookmark them rather than share them.

## Libraries/Resources

**Best for**: Reference material

**Examples**:
- Icon library
- Template library
- Code snippet library
- Example gallery
- Industry directory
- Resource list
- Swipe file collection
- Font pairing tool

**Why they work**:
- High SEO value
- Ongoing traffic
- Establishes authority
- Linkable asset

**Implementation tips**:
- Make searchable/filterable
- Allow easy copying/downloading
- Update regularly
- Accept community submissions
- For templates, the template is the product: put instructions inside it and add a filled-in example
- A downloadable template offered for an email is a lead magnet; see the lead-magnets skill

- Quizzes/assessments
- Simulators
- Comparison tools
- Decision trees
- Configurators

**Why they work**:
- Engages deeply
- Demonstrates expertise
- Shareable
- Memory-creating

**Implementation tips**:

- Show immediate feedback
- Lead to deeper resources
- Capture engaged users

### Data visualizations

Market maps, benchmark dashboards and filterable comparisons. Unique data is the moat: journalists and bloggers link to datasets they can't get elsewhere.
- Interactive beats static for engagement
- Offer embed code so other sites can show it with a link back
- Refresh the data on a schedule; stale data loses links once someone notices

## Build vs. No-Code by Type

| Type | No-code options | When to build custom |
|------|-----------------|----------------------|
| Calculator | Outgrow, Calconic, Typeform | Complex logic, or when brand and speed matter |
| Generator | Typeform + Zapier, LLM wrappers | When you need custom LLM behavior |
| Checker | Limited; usually needs development | Almost always (URL crawling, text analysis) |
| Grader | Outgrow, Involve.me | When the rubric is fixed and simple, no-code works; otherwise build |
| Converter | Existing no-code utilities | Rarely needed; conversions are simple to build |
| Template | Google Docs, Notion, Canva | When document quality matters |
| Data visualization | Flourish, Observable | Complex or highly interactive data |

## Ten Times Better Than the Existing Free Option

When a free tool already does the job, build only with one of these reasons:

1. **Niche specificity** — the existing tool is generic; yours fits your audience's workflow
2. **Better UX** — existing tools are clunky or take too many steps
3. **Integrated next step** — existing tools drop the user after the result; yours offers next steps or a trial
4. **Unique data or model** — yours uses data others don't have
5. **Shareable output** — existing tools return a table; yours produces a card, a report or an embed

"The same tool, but ours" is a traffic fight you won't win. Build the tool that does what the others don't.
