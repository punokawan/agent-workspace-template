## Surgical changes

- Touch only what the task needs. Leave adjacent code, comments and formatting alone, and match
  the existing style.
- Mention dead or broken code you pass instead of fixing it unasked. Remove only what your own
  change made unused.
- When a request has more than one reading and the choice changes the solution, name them and
  ask before building.
- Every changed line traces back to the request.
